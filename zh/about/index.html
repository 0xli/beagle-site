// 关于

一个身份连接通信、智能体与 私有服务 。

Beagle 基于一个简单理念：属于你的身份应该同时适用于人与人通信、智能体协作、文件交换和私有机器访问，而不是让每项能力都变成新的平台账户。

// beagle 是什么

一款给人用、也给 AI 智能体用的聊天 App。它和大多数聊天 App 相比，有六点不同。

01
它运行在开放的网络上，而不是某家公司的服务器上。

Beagle Chat 是 Decent Network 上的一个 App，这个网络的协议和 SDK 都是公开的。你的好友用任何遵守这个协议的 App，都能和你联系。

02
你的身份与生俱来。

它诞生在你自己的设备上，不是平台分配给你的。不需要手机号，不需要邮箱地址，也不需要密码。

03
只有好友才能联系到你。

陌生人只能给你发一样东西：好友请求。在你接受之前，其他任何东西都发不进来。

04
消息从你的设备发到好友的设备，全程加密。

中间没有哪家公司的服务器读取或保存你的聊天内容。

05
好友离线时，照样能收到你的消息。

消息会以加密形式存放在离线存储上等着对方，最多等 14 天。

06
智能体可以成为你的联系人。

AI 助手或程序可以拥有自己的 Beagle 身份，你和它聊天就像和人聊天一样。

// 最大的不同
开放的网络，而不是某家公司的服务器。

WhatsApp、Telegram 和 Signal 各自是一家公司的服务：服务器由这家公司运行，谁能使用由它决定，连接它的 App 也由它来写或批准。

Beagle Chat 是 Decent Network 上的一个 App。Decent Network 是一个协议公开的开放网络。Beagle Chat 是这个网络的客户端，就像邮件程序或网页浏览器是客户端一样：任何人都可以再写一个，只要遵守协议，所有客户端都能互通。

就像比特币实现了无需第三方中介的信任，Decent Network 让社交和通讯实现了自主和平等：每个人掌握自己的身份，每个人都以平等的身份参与。

你不会被绑在一个 App 上。

手机上的聊天 App、电脑上的程序、浏览器里的一个页面、服务器上的智能体：不同的客户端适合不同的人和用途，都能联系到同样的好友。

不需要任何人许可。

创建身份、在这个网络上做 App 或智能体、运行引导节点，都不需要向谁申请。协议、SDK 和引导节点的代码都是公开的。

没有超级用户。

在 Decent Network 里，没有谁（包括我们）拥有管理所有用户的账号。没有人能读你的聊天、封停你的身份或拿走你的好友。你的身份、好友列表和聊天记录都在你自己的设备上，属于你自己。

没有哪一家公司拥有这个网络。

引导节点已经由不止一家运营方运行。目前 App 默认使用的离线存储、推送和桥接服务由我们运行；想自己运行的合作伙伴可以拿到这些服务的代码。

开发者和我们从同一个起点出发。

我们自己的 App 用的就是任何人都能用的公开 SDK，文档在 decent.network/docs。

// 向 ai 敞开
智能体是网络的正式成员，而不是平台上的客人。
WhatsApp

要走 Meta 的企业平台：企业账号、认证、给智能体一个专用手机号，主动发消息还要受规则限制。

Discord

要注册一个 Bot（机器人），保管好它的令牌，申请权限，再被邀请进每一个服务器。

Beagle

智能体就是另一个客户端。用公开的 SDK，它生成自己的身份，发送和接受好友请求，和所有 Beagle App 通信，还能接电话。不用注册，不用审批，也没有特殊的机器人账号。

这已经在发生：Muse 和 Grok Bot 是用我们的 SDK 做的智能体，它们和 Beagle 上的人聊天，也都接过 Beagle iPad App 打来的语音电话。视频通话也可以用同样的方式实现。

// decent network
Beagle 是产品界面，AgentNet 是机器引擎，Decent Network 是协议。

三个名字描述同一系统的不同层级：Beagle 面向人，AgentNet 面向机器与智能体，Decent Network 提供身份、关系、发现和加密传输。阅读论述与白皮书深入了解。
