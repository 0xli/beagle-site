在 Windows 上安装 CLI(WSL2)

在 WSL2 内运行 AgentNet，并让 Windows 浏览器安全访问本地控制台。除非企业策略限制，否则优先用原生安装指南。

2026 年 7 月

准备 WSL2

01
安装 WSL2

以管理员身份打开 PowerShell，执行后按提示重启。

wsl --install
02
打开 Ubuntu

完成 Linux 用户名与密码设置，并在 WSL 内安装 Node.js 20+。

03
安装软件包

AgentNet 是守护进程和 agentnet 命令,Beagle 是你使用的界面。Beagle 必须一并写在这里 —— 全局安装只链接它自己的命令,agentnet 不会出现在 PATH 里。

sudo npm install -g pm2 @decentnetwork/lan @decentnetwork/beagle
04
创建身份与服务

以 WSL 普通用户初始化，再安装网络助手。

agentnet init
sudo agentnet service install

启动 Beagle 聊天

只当聊天工具这一步就够——消息和文件点对点直达。绑定 0.0.0.0 是为了让 Windows 浏览器能访问 WSL 里的服务。

pm2 start "beagle --host 0.0.0.0 --port 8766" --name beagle-ui
pm2 save

可选:给 Windows 浏览器的代理路由

只有想让浏览器流量走网络时才需要。只把 Beagle 当聊天工具的话,跳过。

pm2 start "agentnet proxy router --listen 0.0.0.0:8889" --name agentnet-router
pm2 save

让 Windows Chrome 使用代理

你从 Windows 浏览,而 Windows 会把 localhost 转发到 WSL,所以让 Windows Chrome 指向 127.0.0.1:8889。在 Windows PowerShell 里运行(不是在 WSL 内),平时的 Chrome 不受影响。

& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" `
  --proxy-server="127.0.0.1:8889" `
  --user-data-dir="$env:TEMP\chrome-beagle" `
  --proxy-bypass-list="<-loopback>"
其他方式

也可以安装 ZeroOmega 或 FoxyProxy 插件,添加 HTTP 代理 127.0.0.1 端口 8889。想让所有网站都走出口?用 agentnet proxy router --all 启动。

验证

agentnet identity show
agentnet doctor
pm2 status
