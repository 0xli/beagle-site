安装

安装桌面应用

下载 macOS 或 Windows 版 Beagle。不需要 Node.js、不需要终端——应用自己装好它要用的一切。

2026 年 8 月

下载

Beagle 自带运行时。机器上有合适的 Node.js 就直接用;没有就给自己装一份私有的,卸载时一起删掉。不往你的系统里加任何东西。

  • **macOS(Apple 芯片)** — Beagle-0.1.4-arm64.dmg,113 MB
  • **Windows(x64)** — Beagle-Setup-0.1.4.exe,97 MB
  • **Windows 免安装版** — Beagle-0.1.4-win.zip,132 MB——解压后运行 Beagle.exe

macOS

01
打开 .dmg,把 Beagle 拖进「应用程序」

常规的拖拽安装。

02
双击 Beagle,然后到系统设置里放行

第一次会被 macOS 拦下,弹框里只有「完成」和「移到废纸篓」——没有「打开」按钮,而且 macOS 15 起「右键→打开」这条路已被 Apple 删掉,点多少次都是同一个框。先点「完成」,然后打开 系统设置 → 隐私与安全性,往下滚到「安全性」,在关于 Beagle 那一行点「仍要打开」,再确认一次就能运行。凡是还在等 Apple 公证的应用都要这么放行一次。

03
等它装完,点「Open Beagle」

首次启动会装它需要的包,网络正常的话一两分钟。面板显示 Running 之后点 Open Beagle,聊天界面就在浏览器里打开了。

Windows

01
运行安装程序

只装给你当前这个用户,不会弹管理员密码。

02
如果 SmartScreen 拦截:「更多信息」→「仍要运行」

Windows 版还没有代码签名证书,所以 SmartScreen 会提示发布者未知。免安装的 .zip 也是同样的提示。

03
等它装完,点「Open Beagle」

和 macOS 一样:首次启动会取它要用的东西,然后面板显示 Running。

第一次运行会发生什么

  • 在你的机器上生成一个身份。没有账号、不用注册——密钥就是身份。
  • 如果这台机器上已经有 Beagle 在跑,应用会问你要不要直接用那个,而不是再起一个。
  • Beagle Help 会成为你的第一个联系人,这样你在还不认识任何人的时候也有地方问。

更习惯用终端,或者要装在服务器上?看 CLI 安装指南——同一张网络、同一套身份模型。
