// 功能

Beagle Chat 把你的 Beagle 身份带进浏览器。

浏览器开着就能收消息
好友、好友请求、端到端加密聊天、未读角标；没有 Beagle 窗口在前台时弹出通知。
一个身份，处处通用
在这里创建，或从桌面端、命令行、app.beagle.chat 导入密钥文件——也可以同样导出。
属于你自己的资料
你的 beagles.eth 名字和头像，以及只保存在本机、可按字段设置公开范围的私密资料。
Fill with Beagle
在有表单的页面上点击 Fill。Beagle Fill 智能体根据你自己的答案库和资料给出建议答案，并先报价。私密字段、手机号和邮箱地址绝不会发送给它，表单始终由你自己提交。
分享当前网页
两次点击，把正在看的页面发给好友。
Solana 钱包是其中一个标签页
创建或导入钱包，收款转账，为 Solana dApp 连接和签名（Wallet Standard）。

Chrome 与 Firefox 上是同一个扩展，只有两点不同。

停靠视图
在 Chrome 中，Beagle 停靠在侧边栏（side panel）；在 Firefox 中，停靠在 Firefox 侧栏（sidebar）。
macOS 钥匙串
通过可选的辅助程序把钱包密钥存入 macOS 钥匙串，仅 Chrome 支持。在 Firefox 中，密钥保存在扩展自身的存储里，并用你的密码加密。

// 存了什么，存在哪里

密钥、消息和钱包都留在你的设备上。

没有账号，没有手机号，中继只转发密文。我们运营的服务中，只有 Fill 智能体会收到网页或资料内容，而且仅在你点击 Fill 时。

01身份密钥

构成你 Beagle 身份的密钥对——在本机生成，保存在扩展自己的存储里，从不外发。

02好友和消息

好友列表、请求和聊天记录都在本机。传输过程端到端加密。

03私密资料

你填写的各项资料，每项都有你设定的公开策略。只存本地。设为“私密”或“每次询问”的字段绝不离开设备；设为“公开”或“联系人”的字段，在你点击 Fill 时可能发送给 Fill 智能体。

04钱包密钥

助记词和私钥用你的密码加密保存。签名在本机完成。

卸载扩展会删除以上全部数据——请先导出身份密钥和钱包助记词。隐私政策准确说明 Fill 智能体会收到什么、保留多久，并列出扩展会连接的每一项网络服务。 隐私政策 →
