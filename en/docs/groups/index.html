Groups: join, chat, and set one up

A Beagle group is a contact that relays each member's message to everyone else. You join it the way you add a friend, and the first person to add it runs it.

November 2026

How a group works

A Beagle group is a group bot: a Carrier identity of its own that passes each member's message on to all the other members. Members who were offline receive what they missed when they reconnect.

  • Joining is adding a friend. Add the group's Carrier address in Beagle, the same way you add a person.
  • The first friend becomes the creator. The first identity to add a new group runs it.
  • Only the creator manages it: renaming the group, giving it a beagles.eth name and profile, removing or blocking members, adding AI agents, and deleting the group.
Add it before you share it

Whoever adds a new group first becomes its creator, and that cannot be handed over later. If you are setting up a group, add its address yourself before you give it to anyone else.

Join a group

01
Get the address

Ask a member for it. Anyone in the group can show it by typing /address, or share it as a QR code.

02
Add it in Beagle

Paste the address into the Add box and send the friend request, exactly as you would for a person.

03
Say hello

Once it is accepted, the group appears as a chat. Type /help to see the commands available to you.

Commands in the chat

Type these in the group chat. The long and short forms do the same thing. /help shows creator-only commands only to the creator.

CommandShortWhoWhat it does
/help/hEveryoneList the commands
/address/aEveryoneShow the group's address, for inviting people
/list/lEveryoneList members with online or offline status
/update <name>/uCreatorRename the group. The rest of the line is the name, spaces included.
/ens register <name>/nCreatorRegister <name>.beagles.eth for the group
/ens show/nEveryoneShow the group's beagles.eth record
/profile avatar <https-url>/pCreatorSet the group's avatar on its record
/profile intro <text>/pCreatorSet the group's description on its record
/profile show/pEveryoneShow the current record
/block <index>/bCreatorBlock a member, by the number /list shows
/del <index>/dCreatorRemove a member, by the number /list shows
/agent add <carrier-address>/gCreatorAdd an AI agent that receives group messages and can reply
/agent del <userid>/gCreatorRemove an agent
/agent list/gCreatorList the group's agents
/exit/eCreatorDelete the group
A new name reaches members after a restart

/update Design Team renames the group, but other members see the new display name only after the group service restarts.

Give the group a beagles.eth name

The creator can register a beagles.eth name for the group and set its avatar and description. The group signs the record with its own key, so the record's owner is the group's own userid, not the creator's.

/ens register my-group
/profile avatar https://example.com/my-group.png
/profile intro Weekly design reviews and release notes.
/profile show
  • The name is one word of 1 to 63 characters: lowercase letters, digits and hyphens. Registration is refused if someone else already owns the name.
  • The avatar is a single https:// URL, up to 512 characters.
  • The intro is the rest of the line, 1 to 200 characters.
  • Changing the avatar or intro keeps the rest of the record and signs it again. Any member can read the record with /profile show or /ens show.

Run your own group server

Operators can run the group service themselves. It runs as a systemd user unit, carriergroup.service, and has a small admin API on port 5000.

Keep the admin API private

Bind port 5000 to localhost or a private network. Do not expose it to the internet.

RequestWhat it does
GET /createMake a new group
GET /groupsList groups: id, address, member count, and name. The newest group is the last entry.
GET|POST /agent/add?group_id=&address=Add an AI agent to a group
GET|POST /agent/remove?group_id=&userid=Remove an agent
GET /agent/list?group_id=List a group's agents
systemctl --user status carriergroup.service

curl http://127.0.0.1:5000/create
curl http://127.0.0.1:5000/groups

# quote any URL that contains &
curl "http://127.0.0.1:5000/agent/add?group_id=<id>&address=<carrier-address>"
curl "http://127.0.0.1:5000/agent/list?group_id=<id>"
curl "http://127.0.0.1:5000/agent/remove?group_id=<id>&userid=<userid>"
01
Create the group

Call /create, then /groups. The new group is the last entry; copy its address.

02
Add it yourself first

Add the address as a friend in Beagle. Being the first friend makes you the creator.

03
Name it

In the group chat, run /update <name>. Optionally register a beagles.eth name with /ens register <name>.

04
Share it

Give people the address or a QR code. They join by adding it as a friend.
